ВЕРСИЯ 1.2.0 (28.11.2025)
- ДОБАВЛЕНА поддержка SYNC-маркеров в протоколе обмена с сервером
- ДОБАВЛЕНЫ константы SYNC_START (0xAA 0x55) и SYNC_END (0x55 0xAA)
- ДОБАВЛЕНА функция WriteToServerWithSync() для отправки пакетов с sync-маркерами
- ИЗМЕНЕНА отправка телеметрии: теперь формат [AA 55][Type + 42 байта + CRC][55 AA] = 52 байта
- ИЗМЕНЕНА отправка ответов на команды: формат [AA 55][Type + Code + Status + DataLen + Data + CRC][55 AA]
- Повышена надёжность восстановления после ошибок CRC
- Улучшен поиск начала пакета при сбоях связи
- Сервер автоматически определяет режим работы (с sync-маркерами или без)
- Обратная совместимость со старыми версиями сервера сохранена
- См. docs/SYNC_MARKERS_IMPLEMENTATION.txt для подробностей

ВЕРСИЯ 1.1.0 (12.11.2025)
- ДОБАВЛЕНА обработка команды TELEMETRY_DATA_FALSE (00 02) от сервера
- ДОБАВЛЕНА автоматическая повторная отправка телеметрии при ошибке
- ДОБАВЛЕНО хранение последних отправленных данных телеметрии (LastSentTelemetry)
- ДОБАВЛЕН счётчик ошибок отправки телеметрии (TelemetryErrorCount)
- ДОБАВЛЕНА функция ResendLastTelemetry() для повторной отправки данных
- Повторная отправка происходит немедленно при получении ошибки от сервера
- Обновлена документация: docs/Telemetry_Fix_Diagram.md (раздел "Обработка ошибок")

ВЕРСИЯ 1.0.0 (10.11.2025)
- ИСПРАВЛЕНА критическая ошибка обработки ответов сервера на телеметрию
- Добавлена функция Master_SendTelemetry() для асинхронной отправки телеметрии
- Устранён конфликт семафоров между Master_Request и CommandReceiver
- Телеметрия теперь обрабатывается корректно независимо от времени отклика сервера
- ДОБАВЛЕНА защита фантомной команды 0x00/0x00 (артефакт ложного IDLE)
- ДОБАВЛЕН мьютекс UART4_Mutex для защиты от конфликта между телеметрией и программированием датчиков
- Решён конфликт использования UART4 тремя процессами (телеметрия, приём команд, программирование)
- См. docs/Telemetry_Fix_Documentation.md для подробностей о телеметрии
- См. docs/UART4_Mutex_Protection.md для подробностей о мьютексе
