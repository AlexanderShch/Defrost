# ✅ Быстрая проверка SYNC-маркеров (v1.2.0)

**Дата**: 28 ноября 2025

## 🎯 Что проверяем

Убеждаемся, что все пакеты от контроллера к серверу имеют формат:
```
[AA 55] [Данные] [55 AA]
```

## ✅ Чек-лист проверки

### Шаг 1: Запуск контроллера

```
[ ] Прошить контроллер v1.2.0
[ ] Подключить к серверу
[ ] Запустить монитор UART4 (если доступно)
```

### Шаг 2: Проверка телеметрии

**Что смотреть**: Пакет раз в 10 секунд

**Ожидаемый формат**:
```
AA 55                    ← Начало sync
00                       ← Type = 0x00 (телеметрия)
XX XX XX ... (42 байта) ← Данные
XX XX                    ← CRC16
55 AA                    ← Конец sync
```

**Проверка**:
```
[ ] Размер пакета = 52 байта
[ ] Начинается с AA 55
[ ] Заканчивается на 55 AA
[ ] Type = 0x00 (третий байт)
[ ] Сервер принимает пакет (логирует "Telemetry received")
```

### Шаг 3: Проверка ответов на команды

**Тестовая команда**: GET_VERSION (Type=0x03, Code=0x02)

**Отправить серверу** → контроллеру:
```
03 02 00 XX XX  (Type=REQUEST, Code=GET_VERSION, DataLen=0, CRC)
```

**Ожидаемый ответ** контроллера:
```
AA 55                ← Начало sync
03                   ← Type = 0x03 (REQUEST response)
02                   ← Code = 0x02 (GET_VERSION)
00                   ← Status = 0x00 (OK)
05                   ← DataLen = 5 ("1.2.0")
31 2E 32 2E 30       ← Data = "1.2.0"
XX XX                ← CRC16
55 AA                ← Конец sync
```

**Проверка**:
```
[ ] Начинается с AA 55
[ ] Заканчивается на 55 AA
[ ] Data = "1.2.0"
[ ] Status = 0x00 (OK)
```

### Шаг 4: Проверка повторной отправки (DATA_FALSE)

**Сценарий**: Симулировать ошибку CRC

1. Сервер отправляет контроллеру:
   ```
   00 02 00 XX XX  (Type=TELEMETRY, Code=DATA_FALSE, DataLen=0, CRC)
   ```

2. Контроллер должен повторить отправку последнего пакета телеметрии:
   ```
   AA 55 [Type=0x00][42 байта][CRC] 55 AA
   ```

**Проверка**:
```
[ ] Контроллер сразу отправляет пакет телеметрии повторно
[ ] Формат: [AA 55]...[55 AA]
[ ] Данные идентичны предыдущей отправке
```

### Шаг 5: Проверка приёма команд

**Важно**: Команды ОТ сервера К контроллеру остались БЕЗ sync-маркеров!

**Отправить серверу** → контроллеру (без AA 55):
```
03 02 00 XX XX  (Type=REQUEST, Code=GET_VERSION, DataLen=0, CRC)
```

**Проверка**:
```
[ ] Контроллер принимает команду БЕЗ sync-маркеров
[ ] Контроллер отвечает С sync-маркерами [AA 55]...[55 AA]
```

## 🐛 Типичные ошибки

### ❌ Ошибка 1: Нет sync-маркеров

**Симптом**:
```
00 14 00 1E ... (начинается сразу с Type)
```

**Причина**: Используется старая функция `WriteToServer()` вместо `WriteToServerWithSync()`

**Решение**: Проверить код, убедиться что v1.2.0 прошита корректно

---

### ❌ Ошибка 2: Sync-маркеры есть, но в неправильном порядке

**Симптом**:
```
55 AA [данные] AA 55  (перепутаны местами)
```

**Причина**: Ошибка в константах или порядке отправки

**Решение**: Проверить:
```cpp
#define SYNC_START_1  0xAA  // Должно быть 0xAA
#define SYNC_START_2  0x55  // Должно быть 0x55
```

---

### ❌ Ошибка 3: Сервер не понимает пакеты

**Симптом**: Сервер логирует "Unknown packet format" или не отвечает

**Причина**: Сервер не обновлён для поддержки sync-маркеров

**Решение**: Обновить сервер на версию с поддержкой автоопределения режима

---

### ❌ Ошибка 4: CRC неверный

**Симптом**: Сервер логирует "CRC error" даже с sync-маркерами

**Причина**: CRC рассчитывается с учётом sync-маркеров (неправильно!)

**Решение**: CRC должен рассчитываться ДО добавления sync:
```cpp
// ПРАВИЛЬНО:
Data_TX_Server.CRC_SUM = MB_GetCRC((uint8_t*)&Data_TX_Server, sizeof(Data_TX_Server)-2);
WriteToServerWithSync(...);  // Sync добавляется ПОСЛЕ

// НЕПРАВИЛЬНО:
WriteToServerWithSync(...);  // Sync добавлены
Data_TX_Server.CRC_SUM = ...;  // CRC теперь неправильный
```

## 🚀 Быстрый тест (1 минута)

### Минимальная проверка:

1. **Подключить логический анализатор к TX линии UART4**
2. **Запустить контроллер**
3. **Дождаться первого пакета телеметрии (10 сек)**
4. **Проверить**: Начинается с `AA 55`, заканчивается `55 AA`
5. **Отправить GET_VERSION**
6. **Проверить**: Ответ с `AA 55` в начале

**Если всё OK** → ✅ SYNC-маркеры работают!

## 📞 Поддержка

**Если что-то не работает:**

3. Проверить UART4: baudrate, parity, stop bits
