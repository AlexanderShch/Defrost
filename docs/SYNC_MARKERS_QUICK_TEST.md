# ✅ Быстрая проверка формата кадра (AA55 + Type + Len, без маркера конца)

**Дата**: 18 декабря 2025

---

## 🎯 Что проверяем

Все пакеты **ОТ контроллера К серверу** имеют формат:

```
[AA 55][Type][Len][Payload...][CRC16]
```

Где:
- `Len` = длина `Payload` (байты после Len и до CRC)
- `CRC16` считается по `[Type][Len][Payload...]`
- маркера конца `55 AA` **нет**

---

## ✅ Чек-лист проверки

### Шаг 1: Телеметрия (Type=0x00)

**Ожидаемый формат**:

```
AA 55                    ← Маркер начала
00                       ← Type = 0x00 (телеметрия)
2D                       ← Len = 45 (0x2D)
... 45 байт Payload ...  ← Time..H..
XX XX                    ← CRC16
```

**Проверка**:

```
[ ] Размер кадра = 2 + 1 + 1 + 45 + 2 = 51 байт
[ ] Начинается с AA 55
[ ] Type = 0x00 (3-й байт кадра)
[ ] Len = 45 (4-й байт кадра)
```

### Шаг 2: Ответ на команду (пример GET_VERSION)

**Ожидаемый ответ контроллера** (пример, Data="1.2.0", DataLen=5):

```
AA 55                ← Маркер начала
03                   ← Type
08                   ← Len = 3 + DataLen = 8
02                   ← Code
00                   ← Status
05                   ← DataLen
31 2E 32 2E 30       ← Data ("1.2.0")
XX XX                ← CRC16
```

**Проверка**:

```
[ ] Начинается с AA 55
[ ] Нет хвоста 55 AA
[ ] Len соответствует (3 + DataLen)
```

### Шаг 3: Повторная отправка после DATA_FALSE

**Сценарий**: сервер отправляет контроллеру `DATA_FALSE` (команда без AA55, формат команд не менялся).

Контроллер должен повторить последнюю телеметрию **в том же формате**:

```
AA 55 00 2D ...(45 payload)... CRC CRC
```

---

## ⚠️ Важно

Команды **ОТ сервера К контроллеру** остаются **без** `AA 55` (как раньше).
