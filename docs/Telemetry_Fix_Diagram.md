## 🔄 Обработка ошибок телеметрии (DATA_FALSE)

### Механизм повторной отправки

Если сервер обнаруживает ошибку в полученных данных телеметрии, он отправляет команду:
```
Type: 0x00 (TELEMETRY)
Code: 0x02 (DATA_FALSE)
```

### Реализация

#### 1. Сохранение данных телеметрии (Data.cpp)

```cpp
static MSGQUEUE_OBJ_t LastSentTelemetry = {};  // Последние отправленные данные
static uint32_t TelemetryErrorCount = 0;       // Счётчик ошибок

void TX_ToServer()
{
    // ... получение данных из очереди ...
    
    // Вычисление CRC
    Data_TX_Server.CRC_SUM = MB_GetCRC(...);
    
    // СОХРАНЯЕМ данные перед отправкой
    memcpy(&LastSentTelemetry, &Data_TX_Server, sizeof(MSGQUEUE_OBJ_t));
    
    // Отправка
    WriteToServer(...);
}
```

#### 2. Функция повторной отправки (Data.cpp)

```cpp
void ResendLastTelemetry(void)
{
    if (LastSentTelemetry.DataType == 0x00)  // Проверка валидности
    {
        // Отправляем сохранённые данные (CRC уже рассчитан)
        WriteToServer((uint8_t*)&LastSentTelemetry, sizeof(LastSentTelemetry));
        
        // Инкрементируем счётчик ошибок
        TelemetryErrorCount++;
    }
}
```

#### 3. Обработка команды DATA_FALSE (CommandReceiver.cpp)

```cpp
CommandStatus_t CommandReceiver_HandleTelemetry(Command_t *cmd)
{
    switch (cmd->commandCode)
    {
        case TELEMETRY_DATA_OK:
            // ✅ Сервер подтвердил приём
            break;
            
        case TELEMETRY_DATA_FALSE:
            // ❌ Сервер сообщает об ошибке
            ResendLastTelemetry();  // Повторная отправка
            break;
    }
}
```

### Преимущества решения

✅ **Автоматическая повторная отправка** - не требуется ждать следующего цикла  
✅ **Минимальная задержка** - повтор происходит сразу при получении ошибки  
✅ **Счётчик ошибок** - позволяет отслеживать качество связи  
✅ **Асинхронная обработка** - не блокирует основной цикл отправки  
✅ **Сохранение данных** - используются те же данные, что были отправлены

### Таблица команд телеметрии

|---------|-----|-------------|----------|

| **TELEMETRY_DATA_FALSE** | 00 02 | Сервер → Контроллер | Ошибка в данных телеметрии |
