**Ключевые элементы:**
```cpp
static MSGQUEUE_OBJ_t LastSentTelemetry = {};  // Последние отправленные данные
static uint32_t TelemetryErrorCount = 0;       // Счётчик ошибок отправки телеметрии

void ResendLastTelemetry(void)
{
    if (LastSentTelemetry.DataType == 0x00)
    {
        WriteToServer((uint8_t*)&LastSentTelemetry, sizeof(LastSentTelemetry));
        TelemetryErrorCount++;
    }
}

// В TX_ToServer() добавлено:
```

## 📝 Примечания

### Важные детали реализации

1. **CRC сохраняется** - Данные сохраняются вместе с уже рассчитанным CRC, что исключает повторные вычисления
2. **Проверка валидности** - `ResendLastTelemetry()` проверяет `DataType == 0x00` перед отправкой
3. **Потокобезопасность** - Используется существующий мьютекс `UART4_Mutex` в `WriteToServer()`
4. **Минимальные изменения** - Добавлена только необходимая функциональность без переделки существующего кода
