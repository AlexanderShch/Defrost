# ⚡ MAX485: Краткая справка по помехоустойчивости

## 🎯 Быстрый ответ

**Максимальный уровень наводки, который выдерживает MAX485:**

| Тип наводки | Значение | Статус |
|-------------|----------|--------|
| **Синфазная (Common-Mode)** | **-7V до +12V** | ✅ Основная спецификация |
| **Дифференциальная** | ±6V (ограничено драйвером) | ✅ Запас безопасности |
| **ЭСР (ESD)** | ±15 kV (встроенная защита) | ✅ Хорошая защита |
| **С TVS-диодами** | ±25 kV ESD | ✅ Отличная защита |

---

## 📊 Что это означает на практике

### ✅ MAX485 справится с:

- **Электромагнитные помехи от двигателей** (синфазные до ±10V)
- **Наводки от ЛЭП** (если в допустимых пределах)
- **Радиопомехи** (подавляются дифференциальным приёмом)
- **Статические разряды** (до ±15 kV без дополнительной защиты)

### ⚠️ Требует дополнительной защиты:

- **Молния** (прямой или непрямой удар)
- **Всплески от частотных преобразователей** (>±12V)
- **Длинные линии в промышленной среде** (>100 м)

---

## 🛡️ Рекомендуемая защита

### Минимальная конфигурация:
```
MAX485 + Витая пара + Терминация 120Ω
```

### Улучшенная конфигурация:
```
MAX485 + Резисторы 10Ω + TVS-диоды + Экранированная витая пара
```

### Промышленная конфигурация:
```
Гальваническая развязка + MAX485 + TVS + Экран + Феррит
```

**Рекомендации:**
1. ✅ Добавить **TVS-диоды** (PESD1CAN или аналог)
2. ✅ Добавить **последовательные резисторы 10Ω**
3. ✅ Проверить наличие **терминатора 120Ω**
4. ⚠️ Использовать **экранированную витую пару** (при длине >30м)
