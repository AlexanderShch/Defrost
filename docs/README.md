## Быстрый старт

### Для разработчиков серверной стороны

1. **Ознакомьтесь с протоколом:**
   - Прочитайте [Быструю справку](CommandReceiver_QuickReference.md)
   - Изучите формат пакетов и команды

2. **Выберите пример для вашей платформы:**
   - Откройте [Примеры кода](CommandReceiver_ServerExamples.md)
   - Скопируйте класс для Python/C#/JS

3. **Протестируйте подключение:**
   ```python
   from defrost_client import DefrostCommandClient
   
   client = DefrostCommandClient('COM3', 19200)
   version = client.get_version()
   print(f"Версия: {version}")
   ```

4. **Интегрируйте в ваше приложение:**
   - Используйте готовые методы из класса
   - Обрабатывайте ответы и ошибки

---

### Для разработчиков контроллера (STM32)

1. **Изучите архитектуру модуля:**
   - Прочитайте раздел "Архитектура модуля" в [основной документации](CommandReceiver_Documentation.md)

2. **Настройте UART и GPIO:**
   - UART4: 19200, 8N1, DMA включен
   - GPIO для RS-485 DE: PROG_MASTER_DE_Pin

3. **Создайте задачу FreeRTOS:**
   ```c
   osThreadId_t CommandReceiverTaskHandle;
   const osThreadAttr_t CommandReceiverTask_attributes = {
     .name = "CommandReceiver",
     .stack_size = 512 * 4,
     .priority = (osPriority_t) osPriorityNormal,
   };
   
   CommandReceiverTaskHandle = osThreadNew(
     CommandReceiver_Task_C,
     NULL,
     &CommandReceiverTask_attributes
   );
   ```

4. **Реализуйте обработчики команд:**
   - Используйте существующие обработчики как шаблон
   - Добавьте новые команды при необходимости

## Примеры использования

### Пример 1: Запуск программы дефростации
```python
client = DefrostCommandClient('COM3')
response = client.start_program()
if response['status'] == 0x00:
    print("Программа запущена")
```

### Пример 2: Мониторинг состояния
```python
while True:
    status = client.get_status()
    print(f"Текущее состояние: 0x{status:04X}")
    time.sleep(5)
```

### Пример 3: Управление реле
```python
# Включить реле 0, 2, 4, 6 (четные)
mask = 0b0101010101010101  # 0x5555
client.set_all_relays(mask)
```

## Отладка и диагностика

### Типичные проблемы

**Команды не принимаются:**
1. Проверьте скорость UART (19200)
2. Убедитесь в правильности подключения RS-485
3. Проверьте управление GPIO DE

**Ошибки CRC:**
1. Проверьте алгоритм CRC (ModBus CRC16)
2. Убедитесь в правильном порядке байтов (Little Endian)
3. Проверьте целостность линии связи

**Таймауты:**
1. Увеличьте таймаут приема (≥5 секунд)
2. Проверьте, что контроллер отвечает
3. Убедитесь, что задача CommandReceiver запущена

### Инструменты отладки

- **Terminal программы:** PuTTY, RealTerm, HTerm
- **Логические анализаторы:** для анализа сигналов RS-485
- **Тестовые скрипты:** см. раздел "Утилиты" в примерах кода
