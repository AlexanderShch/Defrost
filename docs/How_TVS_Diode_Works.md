# 🔌 Как работает TVS-диод (Transient Voltage Suppressor)

**TVS-диод** - это полупроводниковый компонент для защиты от всплесков напряжения  
**Дата**: 12 ноября 2025

---

## 🎯 Принцип работы TVS-диода

### Основная идея

TVS-диод работает как **"клапан давления"** для электричества:

```
Нормальное напряжение:    Всплеск напряжения:
┌─────────────┐           ┌─────────────┐
│             │           │             │
│   TVS-диод  │           │   TVS-диод  │
│   (закрыт)  │           │  (открыт!)  │
│      │      │           │      │      │
│      ↓      │           │      ↓      │
│     ∞Ω      │           │    0.1Ω     │
│      │      │           │      │      │
│     GND     │           │  ──► GND    │
└─────────────┘           └─────────────┘
  Ток = 0                   Весь ток в GND!
```

## 📊 ВАХ (Вольт-Амперная Характеристика) TVS-диода

### График работы

```
        Ток (A)
          ↑
          │         Область пробоя
     10A  ├─────────────────
          │               /
      5A  ├─────────────/    ← TVS открывается
          │           /        и отводит ток
      1A  ├─────────/
          │       /
          │     /
          │   / ← Точка пробоя (Breakdown)
    0.1mA ├─/───────────────────────
          │                         
        0 ├─────────────────────────────► Напряжение (V)
          0   5V  10V  15V  20V  30V
                      ↑
                  V_breakdown
                  (например, 15V)
```

### Ключевые точки:

| Напряжение | Состояние | Ток | Сопротивление |
|------------|-----------|-----|---------------|
| **0-12V** | Закрыт | <1 мкА | ~∞ Ω |
| **15V** | Начало пробоя | 1 мА | ~15 кΩ |
| **20V** | Работа | 1 A | ~20 Ω |
| **35V** | Максимум | 10 A | ~3.5 Ω |

## ⚡ Как TVS защищает схему

### Сценарий 1: Нормальная работа (сигнал 5V)

```
Линия RS-485: 5V
      │
      ├────────► MAX485 (получает 5V) ✅
      │
   [TVS 15V]    ← TVS закрыт (5V < 15V)
      │           Сопротивление = ∞
      ▼           Ток = 0
     GND
```

**Результат:** TVS не мешает работе, прозрачен для сигнала

---

### Сценарий 2: Всплеск напряжения (100V)

```
Всплеск 100V на линии:
      │
      ├─────────────┐
      │             │
      │          [TVS 15V]  ← TVS открывается при 15V!
      │             │          Сопротивление ≈ 0
      │             ▼
      │            GND (отводит ток)
      │
      ├──[35V]───► MAX485 (видит только 35V!) ✅
      │
     (99% энергии ушло в GND через TVS)
```

**Результат:** 
- TVS ограничивает напряжение до 35V
- MAX485 выдерживает 35V кратковременно
- Устройство защищено! ✅

## 🔬 Внутреннее устройство TVS-диода

### Структура (упрощённо)

TVS-диод - это **лавинный диод** специальной конструкции:

```
       Анод                Катод
         │                   │
    ┌────▼───────────────────▼────┐
    │                             │
    │   P+  │  N  │  N+  │  N++  │ ← Слои полупроводника
    │       │     │      │       │
    │       └─────┴──────┘       │
    │      Область обеднения     │
    └─────────────────────────────┘
```

**При превышении V_breakdown:**
1. В области обеднения начинается **лавинный пробой**
2. Электроны получают энергию и выбивают другие электроны
3. Лавина носителей → резкое увеличение тока
4. Напряжение остаётся почти постоянным (ограничивается)

## 🔧 Типы TVS-диодов

### 1. Однонаправленный (Unidirectional)

```
        Символ:           ВАХ:
                        I ↑
        ──|>|─          │    ╱
          ─┴─           │  ╱
          GND           │╱___________
                     ───┼────────────► V
                        0   +15V
                        
Работает только в одном направлении
```

**Применение:** DC цепи (питание 5V, 12V)

### 2. Двунаправленный (Bidirectional)

```
        Символ:           ВАХ:
                        I ↑
        ──|><|─         │    ╱
          ─┴─           │  ╱
          GND        ───┼╱─────────► V
                      ╱ 0  +15V
                    ╱   │
                        │
                      -15V
                      
Работает в обоих направлениях
```

**Применение:** AC цепи, RS-485 (±12V сигналы)

## 📊 Основные параметры TVS-диода

### Для примера: SMBJ15CA

| Параметр | Значение | Описание |
|----------|----------|----------|
| **V_RWM** (Standby) | 15V | Рабочее напряжение (TVS закрыт) |
| **V_BR** (Breakdown) | 16.7-18.5V | Напряжение пробоя (начало работы) |
| **V_C** (Clamping) | 24.4V @ 1A | Напряжение ограничения |
| **I_PP** (Peak Pulse) | 24.6A | Максимальный импульсный ток |
| **P_PP** (Power) | 600W | Импульсная мощность (10/1000 мкс) |
| **C** (Capacitance) | ~1000 pF | Ёмкость (влияет на высокие частоты) |

### Важная формула

```
P_PP = V_C × I_PP

Пример:
V_C = 24.4V
I_PP = 24.6A
───────────────
P_PP = 600W

Это импульсная мощность!
Постоянно такую мощность TVS не выдержит.
```

## ⚙️ Как выбрать TVS-диод

### Шаг 1: Определить рабочее напряжение

```
V_RWM > V_сигнал_макс × 1.2

Для RS-485:
- Сигнал: ±5V дифференциально
- Синфазное: ±7V
- Выбираем: V_RWM ≥ 12V

✅ Подходит: SMBJ15CA (V_RWM = 15V)
❌ Не подходит: SMBJ5.0CA (будет ограничивать сигнал!)
```

### Шаг 2: Проверить напряжение ограничения

```
V_C < V_защищаемой_схемы_макс

Для MAX485:
- Максимум (кратковременно): ~40V
- Выбираем TVS с V_C < 40V

✅ Подходит: SMBJ15CA (V_C = 24.4V @ 1A)
```

### Шаг 3: Проверить энергию импульса

```
Энергия = (V × I × t) / 2

Пример молнии (симулятор):
V = 1000V
I = 10A
t = 10 мкс
─────────────────
E = (1000 × 10 × 10×10⁻⁶) / 2 = 0.05 Дж

TVS SMBJ15CA:
P_PP = 600W для 10/1000 мкс
E_max ≈ 0.3 Дж

✅ Справится!
```

### Когда использовать TVS:

✅ **Используйте TVS когда:**
- Нужна быстрая защита (наносекунды)
- Защита сигнальных линий (RS-485, USB, Ethernet)
- Точное ограничение напряжения
- Импульсные помехи (ЭСР, молния, коммутации)

❌ **Не используйте TVS когда:**
- Очень высокие энергии (используйте GDT + TVS)
- Постоянное перенапряжение (используйте регулятор)
- Очень высокие частоты (>1 ГГц, ёмкость влияет)

## 🧪 Практический пример: Защита RS-485

### Задача
Защитить линию RS-485 (MAX485) от всплесков до 100V

### Решение

```
Линия RS-485 (A)
      │
   [10Ω]           ← Ограничение тока
      │
   [SMBJ15CA]     ← TVS-диод
      │
     GND
      │
   MAX485 (Pin A)
```

### Расчёт работы при всплеске 100V:

**1. TVS открывается при ~17V:**
```
Напряжение на TVS: 17V
Остаток на резисторе: 100V - 17V = 83V
Ток через резистор: I = 83V / 10Ω = 8.3A
```

**2. При токе 8.3A TVS ограничивает напряжение:**
```
V_C ≈ 24.4V + (8.3A - 1A) × 0.5Ω ≈ 28V

Напряжение на MAX485 ≈ 28V
```

**3. Энергия рассеивается:**
```
- На резисторе 10Ω: P = 8.3² × 10 = 689W (импульс!)
- На TVS: P = 28V × 8.3A = 232W (импульс!)
- На MAX485: минимум (защищён!)
```

**Результат:** MAX485 видит только ~28V вместо 100V! ✅

## 💡 Практические советы

### 1. Размещение TVS на плате

```
❌ НЕПРАВИЛЬНО:

Линия ──[10м дорожки]──[TVS]──[10м дорожки]──MAX485
                         │
                        GND

Проблема: Длинные дорожки = индуктивность
         Всплеск успеет повредить MAX485!
```

```
✅ ПРАВИЛЬНО:

Линия ──[TVS]──[короткая дорожка]──MAX485
         │
        GND (толстая дорожка или plane)

Правило: TVS как можно ближе к защищаемой IC!
```

### 2. Соединение с землёй

```
❌ НЕПРАВИЛЬНО:

[TVS]───[тонкая дорожка 0.2мм]───GND

Проблема: Индуктивность дорожки создаёт падение напряжения
         L × dI/dt может быть значительным!
```

```
✅ ПРАВИЛЬНО:

[TVS]═══[толстая дорожка ≥1мм]═══GND plane
   │
   └════[переходное отверстие]════GND plane (нижний слой)

Правило: Минимизировать индуктивность пути к земле!
```

### 3. Последовательный резистор обязателен!

```
❌ БЕЗ РЕЗИСТОРА:

Линия ────[TVS]────MAX485
           │
          GND

Проблема: При мощном всплеске весь ток через TVS
         TVS может выйти из строя!
```

```
✅ С РЕЗИСТОРОМ:

Линия ──[10Ω]──[TVS]────MAX485
                 │
                GND

Резистор:
- Ограничивает ток через TVS
- Рассеивает часть энергии
- Увеличивает надёжность
```

## ✅ Заключение

### Как работает TVS-диод (кратко):

1. **Нормальная работа** (V < V_breakdown):
   - TVS закрыт, сопротивление ∞
   - Не влияет на схему

2. **Всплеск напряжения** (V > V_breakdown):
   - TVS открывается за 1-10 нс
   - Сопротивление падает до ~0.1-10 Ω
   - Отводит ток в землю
   - Ограничивает напряжение до V_clamping

3. **После всплеска**:
   - TVS закрывается
   - Возвращается в режим ожидания

### Ключевые преимущества TVS:

✅ Очень быстрая реакция (1-10 нс)  
✅ Точное ограничение напряжения  
✅ Многократное использование (не сгорает)  
✅ Компактный размер  
✅ Надёжная защита

### Для RS-485 рекомендуем:

```
Компоненты:
- TVS: SMBJ15CA или PESD1CAN
- Резистор: 10Ω 0805 или 1206
- Размещение: Близко к разъёму
- Заземление: Толстые дорожки (≥1мм)
```
