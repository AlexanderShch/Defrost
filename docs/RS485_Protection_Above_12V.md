# 🛡️ Защита линии RS-485 от наводок более 12В

**Проблема**: MAX485 выдерживает синфазное напряжение только до +12V  
**Решение**: Многоступенчатая защита с ограничением напряжения  
**Дата**: 12 ноября 2025

---

## ⚡ Опасности превышения 12В

### Что может произойти:

```
Наводка > +12V:
  ├─> Пробой входных цепей MAX485 ❌
  ├─> Повреждение микроконтроллера ❌
  ├─> Выход из строя всего устройства ❌
  └─> Потеря связи с сервером ❌
```

### Источники опасных наводок:

| Источник | Напряжение | Длительность |
|----------|------------|--------------|
| **Молния (непрямой удар)** | 100V - 1000V | 1-100 мкс |
| **Коммутация мощных нагрузок** | 50V - 500V | 0.1-10 мс |
| **Повреждение изоляции ЛЭП** | 230V AC | Постоянно |
| **Частотные преобразователи** | 20V - 100V | Импульсы |
| **ЭСР (статика)** | 1kV - 25kV | <1 мкс |

---

## 🛡️ Решение 1: TVS-диоды (Рекомендуется!)

### Принцип работы

**TVS (Transient Voltage Suppressor)** - ограничивает напряжение на заданном уровне.

```
Без TVS:              С TVS:
    
Наводка 100V          Наводка 100V
     │                     │
     ↓                     ↓
   MAX485              [TVS диод]
     │                     │ 
     ❌                   ↓ (ограничено до 12V)
  Повреждён!           MAX485
                          │
                          ✅
                       Работает!
```

### Схема подключения TVS-диодов

```
                  Контроллер
         ┌─────────────────────────┐
         │  STM32F429              │
         │  UART4                  │
         │    TX ─┐                │
         │    RX ─┤                │
         │    DE ─┤                │
         └────────┼────────────────┘
                  │
              ┌───▼────┐
              │ MAX485 │
         ┌────┤ A   RO ├────┐
         │┌───┤ B      │    │
         ││   └────────┘    │
         ││                 │
      [10Ω]              [120Ω]  ← Терминатор
         ││                 │
         │└─────┬───────────┤
         │      │           │
      [TVS-A] [TVS-B]      │
         │      │           │
        GND    GND         GND
         │      │
         A      B  ───→ К серверу
```

### Пример схемы с TVS

```
     RS-485 линия
         │
    ┌────┴────┐
    A         B
    │         │
  [10Ω]    [10Ω]      ← Последовательные резисторы
    │         │
    ├─────────┤
    │         │
  [TVS]    [TVS]      ← TVS-диоды (PESD1CAN)
    │         │         Ограничение до ~35V
   ─┴─       ─┴─
   GND       GND
    │         │
    A         B
    │         │
  MAX485   MAX485
```

**Защита работает так:**
1. Наводка 100V → TVS пробивается при 35V
2. Избыточная энергия стекает в землю
3. MAX485 видит только 35V (превышение, но кратковременное)
4. Резисторы 10Ω ограничивают ток через TVS

## 🛡️ Решение 2: Газовые разрядники (GDT)

### Для очень мощных импульсов (молния)

**GDT (Gas Discharge Tube)** - разрядник для отвода больших токов.

```
Схема двухступенчатой защиты:

     Линия RS-485
         │
         A
         │
    [GDT 90V]  ────┐         ← Первая ступень
         │         │            (отводит основную энергию)
         │        GND
         │
      [10Ω]                   ← Развязка
         │
      [TVS 35V]  ────┐        ← Вторая ступень
         │           │          (точное ограничение)
         │          GND
         │
      MAX485
```

### Рекомендуемые GDT

| Модель | Напряжение | Ток | Применение |
|--------|------------|-----|------------|
| **CG2020L** | 90V | 5kA | Молниезащита |
| **CG1206** | 75V | 3kA | Промышленная защита |
| **B88069X8990T502** | 90V | 10kA | Телеком линии |

### Полная схема с GDT + TVS

```
                Линия RS-485
                     │
                ┌────┴────┐
                A         B
                │         │
           [GDT 90V]  [GDT 90V]     ← Первая ступень
                │         │            (молния, мощные импульсы)
               ─┴─       ─┴─
               GND       GND
                │         │
              [10Ω]    [10Ω]         ← Развязка
                │         │
            [TVS 35V] [TVS 35V]      ← Вторая ступень
                │         │            (точное ограничение)
               ─┴─       ─┴─
               GND       GND
                │         │
                A         B
                │         │
            ┌───▼─────────▼───┐
            │     MAX485      │
            └─────────────────┘
```

**Как работает защита:**
1. **Молния 1000V** → GDT пробивается при 90V, отводит основной ток (до 10kA!)
2. Остаток **~90V** → проходит через резистор 10Ω (падение напряжения)
3. **~80V** → TVS ограничивает до 35V
4. **35V** → MAX485 выдерживает кратковременно (TVS быстро стекает ток в землю)

## ⚠️ Важные замечания

### 1. Заземление критично!

```
❌ НЕПРАВИЛЬНО:           ✅ ПРАВИЛЬНО:

TVS──(плохой контакт)     TVS───┬──GND (толстая дорожка)
     GND                        ├──GND plane
                                └──Chassis GND
```

**Требования:**
- Дорожка GND для TVS: ≥1 мм ширина
- Минимальная индуктивность
- Соединение с chassis (если металлический корпус)

### 2. Размещение компонентов

```
Линия ──→ [GDT] ──→ [10Ω] ──→ [TVS] ──→ MAX485
         │           │           │
         ↓           ↓           ↓
        GND         GND         GND
     (близко!)
```

**Правила:**
- GDT как можно ближе к входу
- TVS рядом с MAX485
- Короткие соединения с GND

### 3. Выбор напряжения TVS

```
Формула: V_TVS_работа > V_сигнал_макс × 1.2

Для RS-485:
- Дифференциальный сигнал: ±5V
- Синфазное смещение: ±7V
- Выбор TVS: 12V рабочее, 24-35V ограничение

✅ ПРАВИЛЬНО: TVS 12V/35V
❌ НЕПРАВИЛЬНО: TVS 5V (будет ограничивать сигнал!)
```
