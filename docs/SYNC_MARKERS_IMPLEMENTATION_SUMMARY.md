## 🔍 Структура пакетов

### ✅ Телеметрия

**БЫЛО**:
```
[Type][42 байта данных][CRC] = 48 байт
```

**СТАЛО**:
```
[AA 55][Type][42 байта данных][CRC][55 AA] = 52 байта
     ↑                                   ↑
  Начало                              Конец
```

### ✅ Ответы на команды

**БЫЛО**:
```
[Type][Code][Status][DataLen][Data...][CRC]
```

**СТАЛО**:
```
[AA 55][Type][Code][Status][DataLen][Data...][CRC][55 AA]
     ↑                                               ↑
  Начало                                          Конец
```

### ⚠️ Команды от сервера (БЕЗ ИЗМЕНЕНИЙ)

```
[Type][Code][DataLen][Data...][CRC]  ← Как раньше, БЕЗ sync-маркеров
```

## ⚙️ Как работает

### 1. Отправка телеметрии:

```
TX_ToServer()
    │
    ├── Формирует Data_TX_Server
    ├── Рассчитывает CRC
    ├── Сохраняет в LastSentTelemetry
    └── Вызывает WriteToServerWithSync()
            │
            ├── Добавляет AA 55 в начало
            ├── Копирует данные
            ├── Добавляет 55 AA в конец
            └── Отправляет через UART4
```

### 2. Повторная отправка (при DATA_FALSE):

```
CommandReceiver получает DATA_FALSE от сервера
    │
    └── Вызывает ResendLastTelemetry()
            │
            └── Вызывает WriteToServerWithSync(LastSentTelemetry)
                    │
                    └── Отправляет тот же пакет с sync-маркерами
```

### 3. Ответ на команды:

```
CommandReceiver получает команду от сервера
    │
    ├── Обрабатывает команду
    ├── Формирует ответ в TX_Response_Buffer
    ├── Рассчитывает CRC
    └── Вызывает CommandReceiver_SendResponse()
            │
            └── Вызывает WriteToServerWithSync(TX_Response_Buffer)
                    │
                    └── Отправляет ответ с sync-маркерами
```
