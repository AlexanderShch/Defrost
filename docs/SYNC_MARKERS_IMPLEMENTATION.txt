Формат кадра от контроллера к серверу (без маркера конца)
=========================================================

1) Маркер начала:
   AA 55

2) Полезная часть кадра:
   [Type][Len][Payload...][CRC16]

   Len = длина Payload (байты после Len и до CRC)
   CRC16 считается по [Type][Len][Payload...]

3) Маркер конца:
   НЕ ИСПОЛЬЗУЕТСЯ (55 AA отсутствует)

Примеры
-------

Телеметрия:
  AA 55 00 2D ...(45 байт payload)... CRC CRC

Ответ на команду:
  AA 55 03 Len Code Status DataLen Data... CRC CRC

Примечание
----------
Команды от сервера к контроллеру остаются без AA 55 (как раньше).
