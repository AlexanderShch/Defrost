# ⚡ Быстрая справка: Защита RS-485 от наводок >12В

## 🎯 Три уровня защиты

### 🥉 Уровень 1: Базовая защита (TVS-диоды)

```
Линия ──[10Ω]──┬──MAX485
               │
            [TVS 35V]
               │
              GND

Стоимость: ~$0.60
Защита: до 500V импульсы
Время внедрения: 30 минут
```

**Компоненты:**
- 2× PESD1CAN (TVS-диоды)
- 2× резистор 10Ω

**Применение:** Офисы, короткие линии (<30м)

---

### 🥈 Уровень 2: Молниезащита (GDT + TVS)

```
Линия ──[GDT 90V]──┬──GND
                    │
                  [10Ω]
                    │
                 [TVS 35V]──┬──GND
                            │
                         MAX485

Стоимость: ~$3.00
Защита: до 1000V, молния 10kA
Время внедрения: 1 час
```

**Компоненты:**
- 2× CG2020L (газовый разрядник)
- 2× SMBJ15CA (TVS-диод)
- 2× резистор 10Ω

**Применение:** Промышленность, длинные линии, зоны с грозами

---

### 🥇 Уровень 3: Максимальная защита (Гальваническая развязка)

```
MCU ──[ADuM1201]──[MAX485]──[TVS]──Линия
     (изоляция 2500V)

Стоимость: ~$6.00
Защита: до 2500V постоянно, импульсы выше
Время внедрения: 2-4 часа (требуется переделка)
```

**Компоненты:**
- 1× ADuM1201 (цифровой изолятор)
- 1× DC-DC 5V изолированный
- 2× SMBJ15CA (TVS-диод)

**Применение:** Жёсткие промышленные условия, частотники, сварка

## 🔧 Что выбрать для Defrost Controller?

### Если линия короткая (<30м):
```
✅ TVS-диоды (Уровень 1)
Компоненты: PESD1CAN + 10Ω
```

### Если линия длинная (>30м) или есть молнии:
```
✅ GDT + TVS (Уровень 2)
Компоненты: CG2020L + SMBJ15CA + 10Ω
```

### Если промышленная среда (частотники, сварка):
```
✅ Гальваническая развязка (Уровень 3)
Компоненты: ADuM1201 + DC-DC + TVS
```

## ⚙️ Быстрый монтаж (Уровень 1)

```
1. Припаять TVS между линией A и GND
2. Припаять TVS между линией B и GND
3. Добавить резисторы 10Ω перед TVS
4. Проверить работу RS-485
5. Готово! ✅
```

**Время:** 30 минут  
**Инструменты:** Паяльник, мультиметр
