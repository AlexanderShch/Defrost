## 🔍 Semantic Versioning

Проект использует семантическое версионирование: `MAJOR.MINOR.PATCH`

- **MAJOR** (1.x.x) - несовместимые изменения API
- **MINOR** (x.1.x) - новая функциональность, обратно совместимая
- **PATCH** (x.x.0) - исправления багов, обратно совместимые

### Как читать номер версии

```
1.1.0
│ │ └─ Patch: исправления
│ └─── Minor: новые функции
└───── Major: несовместимые изменения
```
